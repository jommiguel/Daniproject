Manual / Laboratório interativo

Aprender com as mãos. Não decorar comandos.

Três exercícios reais para perceberes a lógica de um projeto. Podes arrastar as peças no computador ou selecionar e clicar no destino no telemóvel e com teclado.

Missão 01 — Ordena o teu primeiro projeto

5 decisões · Do zero ao GitHub

Arrasta os passos para a ordem correta. Se preferires, seleciona um passo e depois escolhe a posição. Podes alterar a ordem quantas vezes quiseres.

Peças disponíveis

O teu plano

Porque é que esta ordem importa?

Primeiro defines o problema; depois preparas o repositório e o ambiente. Pedes à IA uma tarefa pequena, testas o resultado e só então guardas/publicas uma versão. Assim consegues perceber e explicar cada decisão.

Missão 02 — Aprende a escrever um bom prompt

Construtor de instruções

Escolhe um objetivo e constrói um prompt que podes copiar para o Claude Code ou Codex. Não executa código: ensina-te a pedir alterações com controlo.

Missão 03 — Do código ao ecrã

Experimenta sem estragar nada

Altera o texto do botão e observa o resultado. Isto demonstra a ligação entre código, interface e comportamento.
